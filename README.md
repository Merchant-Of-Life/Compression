# IMAGE COMPRESSOR!!!

just drop an image in, pick your quality slider, and hit compress. there's also a split-view slider so you can compare the before-and-after quality before downloading!. And Nothing is being uploaded to the Cloud! The Comppression is done On YOUR device!

## HOW THIS WAS MADE
this project was made with plain html, css, and vanilla javascript using the canvas api :D

## TECHNOLOGY USED
HTML5 |
CSS3 |
Vanilla JavaScript (ES6+) | 
TML5 Canvas API

## HOW TO RUN THE PROJECT :)

You can Either go to the website [Compression](https://merchant-of-life.github.io/Compression/)

## OR

Clone the source code to your device
git clone https://github.com/Merchant-Of-Life/Compression/

Open the project

double click index.html to open it directly in your browser!
(or run python3 -m http.server 8000 if you want a local server)
and be joyous!
